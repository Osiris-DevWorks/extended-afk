# Test Plan

The tester checklist for the release in progress. Amr runs it on the exe that the release PR's **Build** workflow uploads (`release/X.Y.Z` → `main`), before the PR merges.

- Each feature pushed to the active `release/X.Y.Z` adds its own section below, titled `### #issue: short name`, with concrete items a tester can mark pass or fail.
- `/release` copies the sections into the release PR body.
- `/start_release` clears them when the next release branch opens.
